About CollegeHub Mini-Project

CollegeHub is an end-to-end full-stack web application designed for academic institution management. It provides a clean separation of concerns:

  • Frontend: Clean, responsive HTML5, CSS3, and Vanilla JavaScript.
  • Backend: Modular Express.js REST API server with connection pooling.
  • Database: Normalized MySQL schema with relational foreign keys.
  • Security: Encrypted bcrypt authentication and express-session state storage.
